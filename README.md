# Candle Cost Calculator

Локальное веб-приложение для расчёта себестоимости, цены и чистой прибыли свечей ручной работы.

## Запуск

Это статическое приложение без сборки и сервера. Откройте файл `index.html` в современном браузере.

Если нужен локальный сервер, из папки проекта можно выполнить:

```bash
python3 -m http.server 4173
```

Затем перейдите по адресу `http://localhost:4173`.

## Публикация в интернете

В проект уже добавлен GitHub Actions workflow для GitHub Pages. После публикации репозитория на GitHub:

1. Сделайте `git push` в ветку `main`.
2. Первый запуск автоматически включит GitHub Pages и опубликует сайт.

GitHub выдаст постоянный адрес вида `https://ваш-аккаунт.github.io/название-репозитория/`. Его можно открыть на телефоне, планшете или любом компьютере; на мобильном сайт также можно установить как приложение.

## Данные

Рецепты, черновик текущего расчёта и значения по умолчанию хранятся локально в `localStorage` браузера. Никакие данные не отправляются на сервер. Поэтому сам калькулятор будет доступен на любом устройстве после публикации, но рецепты не синхронизируются между устройствами — для этого во второй версии потребуется аккаунт и облачная база данных.

## Структура

- `index.html` — интерфейс и доступная семантическая разметка.
- `styles.css` — адаптивный визуальный слой.
- `app.js` — модель расчётов, валидация, localStorage и интерактивность.
- `assets/` — логотип «Пряная гармония» и иконки для установки сайта на телефон.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация на GitHub Pages.
